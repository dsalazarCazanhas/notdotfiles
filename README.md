# notdotfiles

> [!NOTE]
> But perhaps might have some interesting things. ~ \0/

## Qué hay aquí

- **install.py** — script de bootstrap para Arch Linux. Instala paquetes base, oh-my-zsh, powerlevel10k, fzf, plugins de zsh, yay, un tema de alacritty, y copia los archivos de configuración a su lugar.
- **config/** — configuraciones de terminal y shell: [alacritty.toml](config/alacritty.toml) y la configuración de [byobu](config/byobu).
- **zsh_powerlevel/** — [zshrc](zsh_powerlevel/zshrc) y [p10k.zsh](zsh_powerlevel/p10k.zsh), usados por el tema powerlevel10k.
- **dircolors** — esquema de colores para `ls`/`dircolors`.
- **misc/** — notas y utilidades sueltas (Arch, OSINT, virtualización, etc.), sin relación directa con el bootstrap.

## Uso

```sh
python install.py
```
